### sap-fiori-prototype-builder - Última alteração foi 26/10/2026

Cria protótipos de aplicações com aparência e padrões de experiência do SAP Fiori, facilitando a validação rápida de interfaces e fluxos antes da implementação definitiva. Antes da criação, pergunta se o layout deve priorizar Mobile (padrão atual) ou Desktop (área de trabalho mais ampla, próxima de um template Fiori).
